# FrameLab — prompts cinematográficos

Uma biblioteca em português para consultar e adaptar prompts de cenas hip-hop, urbanas, cyberpunk e surreais. Explore as cenas por tema, iluminação, ambiente e composição; escolha **Adaptar esta cena** para carregá-la no editor e personalize personagem, ação e enquadramento.

## Usar

Abra `index.html` em um navegador moderno. Não é necessário instalar dependências nem iniciar um servidor. O prompt é montado em inglês para uso em ferramentas de geração de imagem, e pode ser ajustado antes de copiar.
