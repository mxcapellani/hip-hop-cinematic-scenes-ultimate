# Instalação e atualização
```bash
git clone https://github.com/mxcapellani/hip-hop-cinematic-scenes-ultimate.git
cd hip-hop-cinematic-scenes-ultimate
```
Copiar pasta inteira `.agents/skills/hip-hop-cinematic-scenes-ultimate` para o projeto alvo. Host deve reconhecer Agent Skills ou carregar explicitamente o arquivo principal. Python é opcional para busca; PyYAML só para validação.
Atualizar preservando mudanças locais, consultar CHANGELOG e repetir testes. Não renumerar originais nem preencher cena 47 como se fosse da fonte. Acrescentar novas criações em namespace separado. Sem APIs ou geração instaladas automaticamente.
